WINDOWS PREVIEW · 0.8.2

ダウンロードと使い方

LaTeXの数式を、Photoshopの本文へ文字として組み込みます。
同じテキストレイヤーのまま、数式をLaTeXへ戻して編集できます。

制作物ごとに数式用フォントを作り、必要な式を追加して使います。通常利用にGit・Node.js・UXP Developer Toolは必要ありません。

入力 本文 $x_i^2$ と $\frac{a+b}{c}$。

変換イメージ 本文 xi2 と a+bc。

01ダウンロード

Paper Math for Photoshop / Windowsプレビュー

配布ページで公開状況をご確認ください。公開済みの場合は、Assetsから下の名前のZIPを選びます。

配布ページを開く 初回の準備へ

配布ファイル：PaperMath-Windows-preview.zip
ソース・プラグイン本体・入力例・通知文書を含みます。SHA-256照合用ファイル

GitHubが自動生成する「Source code」のZIPとは別のファイルです。配布ZIPをすべて展開して使ってください。このページはHTMLマニュアルです。ブラウザ版のツールは開発中です。

対象
WindowsのPhotoshop。プラグインの導入にはCreative Cloudデスクトップアプリを使います。
別途必要
MiKTeXなどのTeX環境。数式を描画するために使います。

Pythonと必要なPythonパッケージは、Setupが専用の場所に用意します。
ネット接続
ダウンロード・初回セットアップ・TeXの追加パッケージ導入時に必要です。

Windows 10 / Photoshop 27.4.0 / MiKTeX 25.12の一環境で動作報告があります。別PCでの初回導入は未確認のプレビュー版です。

02初回の準備

  1. ZIPをすべて展開する

    ダウンロードしたZIPを展開し、中の PaperMath フォルダーを保存します。ZIPを開いたまま、中のファイルを直接実行しないでください。

    フォルダー内の FIRST_START.html からも基本の手順を読めます。

  2. TeXを用意する

    MiKTeXの配布サイトからWindows版を導入します。追加パッケージのインストールを求められた場合は、内容を確認して導入します。

    必要なTeXの構成

    コマンドは pdflatex・lualatex・kpsewhich、パッケージは standalone・amsmath・amssymb が必要です。不足は Check_Paper_Math.cmd で確認できます。

  3. Setupを実行する

    Setup_Paper_Math.cmd をダブルクリックし、準備が完了するまで待ちます。初回はネット接続が必要です。

    Pythonを手動で導入・選択する操作は不要です。

  4. Photoshopプラグインをインストールする

    Install_Photoshop_Plugin.cmd をダブルクリックし、Creative Cloudの確認画面でインストールします。

    確認画面が出ない場合は Install_Photoshop_Plugin_Alternative.cmd を試してください。完了はCreative Cloudのプラグイン管理と、Photoshopの「プラグイン」メニューで確認します。

ここまで済んだら、次の手順でPaper Mathを起動します。

03毎回の起動

  1. Startを開く

    Start_Paper_Math.cmd をダブルクリックします。開いた処理用ウィンドウは、作業中はそのままにします。

  2. Photoshopでパネルを開く

    Photoshopの「プラグイン」→「Paper Math」を開きます。

使い終わったら
PSDを保存し、Startのウィンドウを閉じるか、そこでCtrl+Cを押して終了します。閉じている間は、数式の生成・変換・復元はできません。

Setupとプラグインのインストールを、毎回行う必要はありません。

04最初の数式を変換する

  1. 本文と数式を入力する

    Photoshopでテキストレイヤーを作り、次のサンプルを入力します。

    本文 $x_i^2$ と $\frac{a+b}{c}$。

  2. 制作物用のフォントを作る

    パネルの「フォントを作成・管理」を開き、制作物が分かる名前を入力して「新規作成して選択」を押します。続きの作業では、同じ制作フォントを選びます。

  3. 数式を変換する

    対象のテキストレイヤーを1つ選び、「数式を変換」を押します。初回は数式フォントが生成され、適用待ちになります。

  4. 生成されたフォントをWindowsへ入れる

    パネルの「フォントの更新先を開く」を押します。選択されたOTFファイルを開き、Windowsのフォント画面からインストールします。既存版がある場合は、Windowsの案内に沿って更新します。

    ファイル名の例：PaperMath-数式図版-a1b2c3d4.otf。Photoshopのフォント一覧に出る名前は英数字の内部名ですが、案内されたファイルを使えば照合できます。

  5. 照合して適用する

    パネルに戻り、「フォントを照合して適用」を押します。本文内の数式が文字として表示されます。

    認識されないときは、PSDを保存してPhotoshopを再起動し、同じ制作フォントとレイヤーで変換し直します。

フォントを入れ直すタイミング
最初の生成時と、新しい式を追加してフォントが更新されたときです。同じ生成版で登録済みの式を使うだけなら、毎回のインストールは不要です。

LaTeXへ戻して編集する

変換時と同じ制作フォントとテキストレイヤーを選び、「数式をLaTeXに戻す」を押します。戻した式を編集し、もう一度変換できます。

復元後の数式は $...$ に統一されます。元の区切り記号・数式内の改行・数式の書式を完全に再現する機能ではありません。

元のレイヤーも残したいとき

標準では同じレイヤーを更新します。「複製を作成する（元レイヤーを保持）」にチェックすると複製へ変換します。作業中の変更はPhotoshopのUndoで戻せます。保存・終了後も必要な元原稿は、別途保管してください。

05入力のルール

数式にする範囲を、LaTeXの区切りで明示します。本文・改行・数式ブロックが混在した原稿も対象です。

数式として読み取る記法
記法入力例
ドル記号$x_i^2$ / $$\sum_{i=1}^{n} i$$
LaTeXの区切り\(x_i^2\) / \[x_i^2\]
数式環境math / displaymath / equation / align / gather / multline

QMDやコードを含む場合

バッククォートで囲んだ行内コードと、コードフェンスの中は変換対象から外し、原文のまま保持します。

本文には $x_i^2$ を使います。

$$
\sum_{i=1}^{n} i
$$

`$ここは行内コードとして保持$`

```python
formula = "$x_i^2$"
```

引用符を文字どおり保持するには、Photoshopの「環境設定 → テキスト → スマート引用符を使用」をオフにします。入力例は配布ZIPの examples/math-input にも入っています。

一部の式が変換されないとき

閉じ記号が曖昧な範囲や、TeXで生成できない個別の式は、原文のまま保留されることがあります。パネルの行番号・抜粋・理由を確認し、原稿を直して再実行するか、その箇所を別レイヤーで扱います。

フォントと対応表の不一致、本文の意図しない変更などを検出した場合は、操作全体を停止します。

06データの保管と更新

数式フォントと、LaTeXの対応表は一組で保管します。 PSDを別のPCで表示するには同じOTFが必要です。LaTeXへ戻すには、そのフォントの対応表も必要になります。

保管に使う操作
操作できること
フォントと対応表をZIPに書き出すパネルの「フォントを作成・管理」から、生成済みOTF・対応表・出所通知を一緒に保存します。
Open_Paper_Math_Data.cmd制作データの保存先を開きます。完全なバックアップは、Startを終了してからこのフォルダー全体をコピーします。

書き出したフォントZIPを自動で読み込む機能は、現在未実装です。継続編集のバックアップには制作データフォルダー全体を保存してください。

保存される場所

配布用ZIPでは、制作データを %LOCALAPPDATA%\PaperMath\data、専用Pythonなどの実行環境を %LOCALAPPDATA%\PaperMath\runtime に保存します。アプリ本体は展開した PaperMath フォルダーにあります。

Paper Mathを更新する

Startを終了し、新しい配布ZIPを別のフォルダーへ展開して Setup_Paper_Math.cmd を実行します。配布版では同じ制作データを引き継ぎます。プラグインが更新された版では、CCXの再インストールも行います。

Gitや「Source code」のZIPを利用していた場合は保存先が異なります。旧開発版からの移行は、保存先と更新の詳細を参照してください。

07困ったとき

まず Check_Paper_Math.cmd をダブルクリックして、環境の点検結果を確認します。点検は一時フォルダーで行われ、PSDやWindows登録フォントは変更しません。

プラグインのインストール画面が出ない

Install_Photoshop_Plugin_Alternative.cmd を試します。導入完了はCreative Cloudのプラグイン管理とPhotoshopのメニューで確認してください。

status = -645 はCreative Cloud連携の失敗です。終了コードが0でも成功とは扱いません。代替起動も含む詳しい切り分けは、導入ガイドに記載しています。

パネルが接続できない

Setupが完了していることを確認し、Start_Paper_Math.cmd を開きます。別の版やフォルダーのStartを起動している場合は、先にそちらを終了します。作業中は処理用ウィンドウを開いたままにしてください。

TeXや数式の生成で止まる

Checkに表示された不足コマンド・パッケージを導入します。個別の式だけが保留される場合は、パネルの行番号・抜粋・理由を確認して、その式を修正します。

フォントが未認識・旧版・不一致になる

制作フォントを確認し、「フォントの更新先を開く」から案内されたOTFをインストール・更新します。認識されなければPSDを保存してPhotoshopを再起動し、同じ制作フォントで変換します。

インストール用ファイルは日本語の管理名を含みますが、Photoshopのフォント一覧の名前は英数字の内部名です。同じ式でも、別の制作フォントに置き換えず、対応するものを使ってください。

数式をLaTeXへ戻せない

変換時と同じ制作フォントと対応表を使います。本文書体を推定できない、数式だけのレイヤーでは復元を停止する場合があります。絵文字や一部の拡張漢字を含むレイヤーも未対応です。

以前の制作フォントが見つからない

Open_Paper_Math_Data.cmd で保存先を確認します。配布ZIPと旧ソース版では保存先が異なります。保存先と更新の詳細に沿って、対応する制作データを使ってください。

解決しない場合は、GitHub Issuesへ、Windows・Photoshop・Creative Cloudの版、再現手順、エラー文、Checkの結果を添えてください。短い再現用の入力例があると確認しやすくなります。

対応範囲について

  • 今回の配布対象はWindowsのPhotoshopです。Macや他のアプリとの相互編集は対象外です。
  • 絵文字や一部の拡張漢字など、BMP外の文字を含むテキストレイヤーは処理できません。
  • 長い原稿や多数の式では、生成フォント・PSDのサイズと処理時間が増えます。必要に応じてレイヤーや制作フォントを分けてください。
  • Photoshopを使わない方向けのブラウザ版は開発中です。現時点では制作フォントの共有・相互追加に対応していません。

詳しくは既知の制約と検証状況を参照してください。
