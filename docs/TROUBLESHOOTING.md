# 困ったときの確認

## プラグインをインストールできない

最初に `Install_Photoshop_Plugin.cmd` を開きます。Creative Cloudの確認画面が出ない場合は、`Install_Photoshop_Plugin_Alternative.cmd` を試します。導入完了はCreative Cloudのプラグイン管理とPhotoshopの「プラグイン」メニューで確認します。

UPIAの `status = -645` は、このプロジェクトで実際に発生したCreative Cloud連携の失敗です。PowerShellの終了コードが0でも成功とは扱いません。詳細は[導入ガイド](INSTALL_WINDOWS.md)を参照してください。

## パネルがサーバーへ接続できない

`Setup_Paper_Math.cmd` が完了していることを確認し、`Start_Paper_Math.cmd` を開きます。処理用ウィンドウを閉じると接続も終了します。

別の作業フォルダーからサーバーを起動中の場合は、そのウィンドウを閉じてから使う版のStartを開きます。同じPCで複数の版を同時に起動しません。既存のフォントが見えない場合は、`Open_Paper_Math_Data.cmd` で保存先を確認します。[保存先と更新](WINDOWS_PREVIEW.md)に旧版からの引継ぎを記載しています。

## TeXやフォントの生成で止まる

`Check_Paper_Math.cmd` を実行します。TeXコマンドやパッケージが不足している場合は、点検に表示された項目を導入します。個別の数式だけ生成できない場合は、パネルに出る行番号・抜粋・理由を確認して、その式を修正します。

曖昧な区切りや個別のTeX構文エラーは、その範囲を原文で保留することがあります。TeX環境や生成物の整合性の問題は全体を停止します。入力規則は[混在サンプル](../examples/math-input/README.md)で確認できます。

## フォントが未認識・旧版・不一致になる

選択している制作フォントを確認し、「フォントの更新先を開く」から案内されたOTFを導入します。ファイル名に日本語の管理名が付きますが、Photoshopのフォント一覧の名前はASCIIの内部名です。

Windowsへの導入後も未認識になる場合は、PSDを保存してPhotoshopを再起動します。再度Startとパネルを開き、同じ制作フォントを選んで変換を行います。登録済みの同じ式に、別の対応表を作って当て直しません。

日本語Family名を使った旧試験版で「期待したPostScript名を返しません」と停止した場合、その試験フォントは自動改名されません。現行版の確認には新しい制作フォントを作成します。試験データは保持されます。

## LaTeXへ戻せない・原文の記号が変わる

変換時と同じ制作フォントを選びます。本文書体を推定できない数式だけのレイヤーでは復元を停止する場合があります。絵文字などBMP外の文字も未対応です。[既知の制約](KNOWN_LIMITATIONS.md)を参照してください。

QMDやコードの引用符を文字どおり保持する場合は、Photoshopの「環境設定 → テキスト → スマート引用符を使用」をオフにします。

## 不具合を報告する

[Issues](https://github.com/goldkiss2010-ai/photoshop-inline-math/issues)へ、Windows・Photoshop・Creative Cloudの版、再現手順、パネルのエラー文、Checkの結果を記載します。原稿全体の代わりに、問題を再現できる短い入力例を添えると確認しやすくなります。
