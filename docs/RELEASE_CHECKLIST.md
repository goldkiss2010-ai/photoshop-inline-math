# Photoshop版の配布準備

## 現在揃っているもの

- Photoshop専用のソース・テスト・通知・導入手順。
- UDTで作成し、ソースと照合した0.8.2の実CCX。
- 元のWindows環境でのセットアップ、CCX導入とUDTなしの使用成功報告。
- 新リポジトリを別フォルダーへ取得し、既存制作データを指定した起動・使用の成功報告（2026-10-16）。
- 制作データを含めず、固定サンプルとソースを同梱する配布ZIP作成処理。
- 通常のCCX導入と、`-645` の環境向け代替ランチャー。
- インストール用コピーとZIP内OTFの日本語ファイル名、従来のASCII内部名での新規作成。
- 日本語OTFファイル名の実機確認完了報告（2026-10-16）。
- 配布ZIPを別フォルダーへ展開したSetup → Start → Photoshopでの変換・復元の成功報告。同じWindows PC、既存CCXを使用（2026-10-16）。試験したZIP・CCXのハッシュとソースは[検証記録](TESTING.md)に固定。
- 混在サンプル6ファイル、最初の変換手順、既知の制約、トラブル対処を配布用の案内へ収録。ZIP内の相対リンクも検査。
- 初回プレビュー用のZIP・SHA-256・公開本文とソースブランチを固定。実機確認済み版と処理・起動・プラグイン等の79ファイルが完全一致。

## 次に確認すること

- 空の制作データ保存先で初回起動し、新規PSD・新規管理フォントの生成、OTF導入、変換・復元・ZIP保存を確認する。
- 日本語ファイル名のOTFをWindowsへ導入し、Photoshopでの適用、PSD再オープン、表示名変更後の式追加を操作ごとに確認する。
- 通常のCCX導入と、代替ランチャー化後の実機操作を確認する。
- [実機スモークテスト](TESTING.md)を操作ごとに記録し、別のWindows環境でも導入する。
- CIが実際のrunnerで実行された結果を確認する。
- 公開に使うZIPを試験済みの配布物と揃える。実行コードを更新した場合は、その版で確認する。
- リポジトリの公開設定を変更し、用意した初回Pre-releaseを公開する。

名称とアイコンは暫定のまま進め、後から検討し直します。プラグインIDと既存フォントの内部識別は継続します。

初回プレビューの公開用本文・配布物のハッシュ・ソース対応は、リポジトリの `release/windows-preview-1` フォルダーで管理します。これは公開作業用で、配布ZIPには収録しません。公開手順はリポジトリ直下の `PUBLISH_WINDOWS_PREVIEW.md` へまとめます。

生成フォントの出所記録と配布条件は、そのフォントに対応して確認します。コードの公開と、任意の生成フォントの包括的な権利判断を同じ完了条件にはしません。

ブラウザ版は旧リポジトリに残します。機能を絞った版のPages公開はPhotoshop版の仕上げ後に検討します。
