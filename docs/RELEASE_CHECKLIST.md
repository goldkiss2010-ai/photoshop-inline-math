# Photoshop版の配布準備

## 現在揃っているもの

- Photoshop専用のソース・テスト・通知・導入手順。
- UDTで作成し、ソースと照合した0.8.2の実CCX。
- 元のWindows環境でのセットアップ、CCX導入とUDTなしの使用成功報告。
- 新リポジトリを別フォルダーへ取得し、既存制作データを指定した起動・使用の成功報告（2026-10-16）。
- 制作データを含めず、固定サンプルとソースを同梱する配布ZIP作成処理。
- 通常のCCX導入と、`-645` の環境向け代替ランチャー。
- 新規フォントの作成時名＋8桁ID、既存フォントの互換読込み（自動試験・Linux実TeX生成で確認）。

## 次に確認すること

- 空の制作データ保存先で初回起動し、新規PSD・新規管理フォントの生成、OTF導入、変換・復元・ZIP保存を確認する。
- 日本語名の新規フォントをWindowsへ導入し、Photoshopのフォント一覧、適用、PSD再オープン、表示名変更後の式追加を確認する。
- 通常のCCX導入と、代替ランチャー化後の実機操作を確認する。
- [実機スモークテスト](TESTING.md)を操作ごとに記録し、別のWindows環境でも導入する。
- CIが実際のrunnerで実行された結果を確認する。
- 配布するZIPとCCXのハッシュ、対応するソースを揃える。
- リポジトリの公開設定と、初回リリースの内容・説明を決める。

名称とアイコンは暫定のまま進め、後から検討し直します。プラグインIDと既存フォントの内部識別は継続します。

生成フォントの出所記録と配布条件は、そのフォントに対応して確認します。コードの公開と、任意の生成フォントの包括的な権利判断を同じ完了条件にはしません。

ブラウザ版は旧リポジトリに残します。機能を絞った版のPages公開はPhotoshop版の仕上げ後に検討します。
