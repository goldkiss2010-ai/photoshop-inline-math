# 由来と分離の範囲

2026-10-15、Photoshop版を仕上げるため、`goldkiss2010-ai/adobe-inline-math` の作業版から `goldkiss2010-ai/photoshop-inline-math` へ分離しました。

新リポジトリは現在の必要なソースから開始します。旧Git履歴・個人の制作データ・生成フォント・PSD・ローカルログは持ち込みません。原コードの著作権表示とAGPL、第三者の通知は維持します。テスト入力と固定6式のサンプル登録簿を含みます。

同梱CCXと一致するUXPの編集可能なソース、Pythonバックエンド、起動スクリプト、テスト、ビルド手順は本リポジトリに収録しています。旧リポジトリへのアクセスを対応ソース取得の前提にはしません。
