# Paper Math — 現行仕様

2026-10-15。Windows向けPhotoshop UXPパネルとローカルPython/TeX処理が対象です。

## 通常操作

本文と数式を混植し、数式をLaTeXへ戻して再編集します。フォントとLaTeX/PUA対応表は制作物ごとのアセットです。同一レイヤーでの往復が標準で、元レイヤーの複製保存は任意です。

| 項目 | 動作 |
| --- | --- |
| 入力 | `$...$`、`$$...$$`、`\(...\)`、`\[...\]` と対応する数式環境を検出 |
| コード混在 | コードフェンスとインラインコードを除外。本文・コード・保留範囲はそのまま保持 |
| 部分成功 | 曖昧な範囲、個別の新規式のTeX構文エラー、段落書式をまたぐインライン式は原文で保留し、独立した式を変換 |
| 復元 | 登録された数式本体を `$...$` に戻す。元の区切り記号・式内改行・数式書式の完全復元は対象外 |
| 管理フォント | 新規作成・選択・追加生成・表示名変更・登録式数の確認・通知付きZIP保存 |
| フォント導入 | 新規生成・更新したOTFをWindowsへ手動インストール |

コード境界・空行・明示displayブロックで探索を分けます。空行を数式探索の境界にするのはPaper Mathの入力規則です。改行はLF/CRLF/CRを解析し、UXPの実際の段落範囲へ投影します。[入力例](../examples/math-input/README.md)を参照してください。

## 処理全体を確定しない条件

対応表の矛盾、所属不明のPUA、意図しない本文変更、対象文書・レイヤー・フォントの切り替わりを検出したら、操作を確定しません。同一レイヤーへの書き込み失敗はPhotoshopの履歴トランザクションで巻き戻します。巻き戻しを確認できない場合は、その事実を表示します。

TeX環境の不足・タイムアウト・PDF/SVGの整合性異常・最終フォント生成失敗は全体停止です。個別のTeX構文失敗と環境全体の失敗は分けます。旧legacyにはフォント変更済みPUAの復元を許す限定的な互換例外があります。

## フォントと書式

管理フォントではプロジェクトIDと内部PostScript名を照合します。表示名だけを変更したときは、内部名・PUA対応・生成OTFは変更しません。登録式数は一意な式の数で、本文中の出現数とは別です。

書式と段落の保持は設計目標ですが、読み戻し検査がすべての外観属性を比較するわけではありません。復元用の本文書体は同じ段落、次に近い段落から取得します。本文書体の手動指定UIは未実装です。

ZIPには生成済みOTF・対応表・管理情報・出所通知を含めます。ZIP保存のための再生成は行いません。ZIP自動読み込み・プロジェクト削除は未実装です。

## UIと入力上の注意

変換・復元を先に配置し、フォント管理・使い方・診断・開発用の試験は通常折りたたみます。保留理由は入力の行番号・文字位置・抜粋とともに表示します。適用待ちの取り消しは生成済みフォントと対応表を保持します。

QMD/TeX原稿の引用符を保持する用途では、Photoshopの「スマート引用符を使用」をオフにします。原稿とバックアップの長期保管は利用者が管理します。Undoは保存・再起動後の原文バックアップではありません。

## 範囲と通知

対象はWindowsのPhotoshopです。Mac、Word、PowerPoint、Illustrator、ブラウザ版との相互編集はこの配布の対象外です。別端末のPSD表示には同じOTFの導入が必要です。

原コードは[AGPL-3.0-only](../LICENSE_SCOPE.md)。生成フォントの輪郭には元フォントの条件が適用され、[出所通知](FONT_SOURCE_NOTICES.md)を添付します。記録の不足や混在を包括的なライセンスへ置き換えません。通常の変換・復元を禁止する条件は増やしません。

実機報告と未確認事項は[検証手順](TESTING.md)、配布準備は[RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)を参照してください。
